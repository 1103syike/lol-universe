# Sim-v2 夜間掃描報告

## 結論摘要

- 計分板 / 對陣圖經濟：統一用 `earnedGold`，地圖預設跳最後一幀，不再出現「計分板有錢、對陣圖還是開局金」的錯位。
- 建築 icon：塔 / 兵營 / 主堡改吃你提供的 PNG（`public/buildings/*_building_{blue|red}.png`）。
- 視野（對齊 wiki）：英雄/塔/泉水 1350、小兵 1200、超兵 1350、兵營/主堡不給視、黃/紅眼 900、河蟹神壇 525×90s；雙方視野藍/紅分色；眼有黃/紅 icon + 放置者；掃眼與數量/時限有實作。計分板經濟拿掉口袋金 fallback，終幀 earnedGold 有不變式。
- 打野：修回城迴圈、落後不硬撞野、空營去等重生點、多意圖（清野債 / 好 gank / 中後期補線）；極端 seed 仍可能 ~24–28 營，均值約 30+。
- 經濟驗收：GPM/CSM/DPM 帶寬通過（打野均值約 270–280 GPM）。

## 打野決策（思考結果 → 實作）

沒有「只刷野」或「只 Gank」正解，用 farmDebt 當節奏尺：

1. **早期（首清前）**：清野優先，壓掉空 gank。
2. **farmDebt ≥ 3 或死亡領先**：先補野、少進對方野、少硬撞。
3. **farmDebt ≤ 1 且線上有推線 / 殘血 / 隊友在**：才抬 gank 分。
4. **每清完一小輪（約每 4 營）且有開線**：短暫把權重讓給 gank，不是永久切模式。
5. **營全空**：走到己方最近營點等重生，不原地發呆、也不無腦 invade。

異常曾出現：泉水旁有錢可買卻一直 `startRecall`（recall 爆到 50+）、以及「離營 2200 內就不回城」導致口袋金堆到 7000 不買裝。兩者已修。

## 眼位機制（實作對照）

- 黃眼（Stealth）：視野 900，時長 120s，個人庫存上限 2、回充 90s，隊伍同場上限 3。
- 紅眼（Control）：視野 900，不逾時，個人同時 1、隊伍 2，需買 75 金。
- 掃眼：Oracle 半徑 750 清敵眼。
- UI：小 icon + 放置英雄頭像；雙方視野模式藍/紅光圈分色。

## 仍偏弱 / 可繼續

- 打野 GPM 相對 LCK 均線仍偏低（營數與擊殺參與不夠穩）。
- 部分 seed 打野營數 ~24、擊殺少：屬多意圖博弈的下緣，不是「完全不 gank」，但仍可再收路徑效率。
- ADC 傷害已從異常高拉回可過驗收，但不同英雄仍可能有 kit 係數落差。
