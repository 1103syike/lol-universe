更新日期：2026-11-08

## 0. 一句話

**驗收成功 = 多種子平均貼近 LCK 分路平均；單場允許極端值，但整體曲線（min / avg / max）要合理。**

---

## 1. LCK 2026 分路曲線（選手賽季分均）

來源：Liquipedia LCK 2026 Player Stats（各位置主要輪換選手）。

| 位置 | GPM min / avg / max | CSM min / avg / max | DPM min / avg / max | DTPM（估計）min / avg / max |
|---|---|---|---|---|
| TOP | 374 / **392** / 406 | 8.2 / **8.5** / 9.2 | 554 / **629** / 673 | 550 / **780** / 1100 |
| JUNGLE | 377 / **394** / 418 | 6.4 / **7.0** / 7.2 | 410 / **467** / 545 | 500 / **700** / 950 |
| MID | 385 / **411** / 448 | 8.6 / **9.1** / 9.7 | 548 / **673** / 845 | 450 / **650** / 900 |
| BOT | 460 / **494** / 511 | 9.7 / **10.2** / 10.7 | 711 / **790** / 831 | 350 / **520** / 750 |
| SUPPORT | 253 / **268** / 288 | 0.9 / **1.1** / 1.2 | 217 / **245** / 271 | 400 / **600** / 850 |

說明：

- 表上的 min/max 是**選手賽季平均**的上下沿，不是單場爆種極限。
- 模擬單場允許比這更寬（例如 CSM 偶發 7 或 12），但**跨種子平均**要貼 LCK avg。
- DTPM Liquipedia 未公開，採用職業常見分路帶，僅作形狀參考。

## 2. 怎麼跑才算一次驗收

| 項目 | 規定 |
|---|---|
| 引擎 | V2 `simulateV2Match` |
| 樣本 | ≥ **3** 個固定種子（預設 `1000 / 1100 / 1200`） |
| 時長上限 | `maxDurationSec = 1800` |
| 陣容 | 標準五路各一，實力接近 |
| 聚合 | 同位置跨場平均 |
| 經濟 | `earnedGold / 分鐘` |

## 3. 硬門檻（測試）

### GPM

| 位置 | 下限 | 上限 |
|---|---|---|
| TOP | ≥ 320 | ≤ 480 |
| MID | ≥ 340 | ≤ 520 |
| BOT | ≥ 380 | ≤ 560 |
| JUNGLE | ≥ 280 | ≤ 430 |
| SUPPORT | ≥ 230 | ≤ 330 |

關係：

1. `SUPPORT < (MID+BOT)/2 * 0.80`
2. `BOT > SUPPORT + 20`、`MID > SUPPORT + 20`
3. `JUNGLE ≤ max(MID, BOT)`

並要求平均 GPM 落在 LCK avg ±14%。

### CSM（主修目標）

| 位置 | 下限 | 上限 | LCK avg |
|---|---|---|---|
| TOP | ≥ 7.2 | ≤ 11 | 8.5 |
| MID | ≥ 7.8 | ≤ 11.2 | 9.1 |
| BOT | ≥ 8.5 | ≤ 12 | 10.2 |
| JUNGLE | ≥ 5.0 | ≤ 9.5 | 7.0 |
| SUPPORT | ≥ 0.5 | ≤ 1.8 | 1.1 |

平均 CSM 須落在 LCK avg ±16%。

打野：野營清完 **+6 CS**；線兵占比 `< 0.35`。

### DPM / DTPM

目前以「有輸出、有承傷、分路形狀不炸」為硬門；LCK DPM 絕對值仍是對齊目標（Carry 仍偏軟時以寬帶驗收）。

| 位置 | DPM 帶 | DTPM 帶 |
|---|---|---|
| TOP | 120–700 | 500–1400 |
| JUNGLE | 250–700 | 400–1300 |
| MID | 220–900 | 400–1200 |
| BOT | 180–900 | 250–900 |
| SUPPORT | 100–450 | 200–900 |
