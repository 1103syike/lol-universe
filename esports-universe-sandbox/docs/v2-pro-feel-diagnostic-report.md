## 0. 一句話結論

V2 目前不是「差一點的職業賽模擬」，而是：

> **十名英雄大部分時間在回城路上反覆決策，幾乎不補兵、不清野、不爭龍、不拆塔，等級卡在 1 附近，40 分鐘全數靠超時強拆主堡收場。**

因此「過程合理」與「結果合理」目前同時不及格。  
問題主因在 **成長迴路（CS／野區／經驗）失效** 與 **AI 被 recall 主導**，不是單純擊殺率偏低。

## 2. 十大調查題：數據 + 程式依據

### 2.1 每分鐘英雄實際行動分布

**數據（even 全場 AI action share）**

| action | 占比 |
|---|---:|
| recall | **68.2%** |
| lane | 20.2% |
| fight | 10.8% |
| farm | 0.5% |
| jungle | 0.2% |
| siege | 0.1% |

**程式依據**

- AI 每秒對每名英雄呼叫一次 `decideForChampion`（`ai/decision.ts`）。
- 回城判斷在最前面；一旦觸發就 `return`，本秒不做其他事。
- 回城條件偏敏感：`hpRatio < 0.22 - 0.04*sense`，或塔下且 `hpRatio < 0.45`。
- 回城是「邊走邊每秒再記一次 recall」，所以占比會被走路時間放大，但即便如此也代表**大量模擬時間耗在撤退狀態**。

**判斷**：行動結構不像職業選手，像「受傷 → 回家 → 再上路 → 再受傷」的狀態機。

---

### 2.2 每分鐘交戰次數與觸發原因

**數據**

- even：場均總擊殺 4.3；團戰叢集（12 秒內 ≥3 死）場均 **0.25**
- 首殺常在 **0:28**（兵線都還沒出：首波 `firstSpawnSec = 65`）
- fight action 有 10.8%，但轉成擊殺極少 → 多半是互相走位／普攻幾下就散

**觸發原因（程式）**

1. `nearestLaneEnemy` 距離 ≤ 1600 就可能進入 fight
2. 打野看到敵方 `hpRatio < 0.55` 且距離 < 2200 就 gank
3. 沒有「線權／視野／冷卻／人數差／物件時間」條件
4. 沒有中期主動尋找開團的戰術層

**判斷**：交戰是「遇見就打」的反應式行為，不是職業賽決策。

### 2.4 小龍／巴龍刷新前後的 AI 行為

**數據（even，龍刷新 ±2 分鐘的 action 計數）**

| 視窗 | recall | lane | fight | jungle | farm |
|---|---:|---:|---:|---:|---:|
| 龍前 2 分 | 2786 | 1436 | 497 | 36 | 45 |
| 龍後 2 分 | 2905 | 1444 | 484 | 0 | 7 |
| 巴龍前 2 分 | 3360 | 960 | 480 | 0 | 0 |
| 巴龍後 2 分 | 3488 | 853 | 484 | 0 | 15 |

**物件結果**：12 場 V2 **0 次**小龍、**0 次**巴龍。

**程式依據**

- 龍／巴龍會依 `objectives.dragonFirstSpawnSec=300`、`baronSpawnSec=1200` 生成。
- AI **沒有任何**「前往龍坑／圍繞物件刷新做決策」的分支。
- 打野只 `nearestAliveCamp`；龍坑若不是最近營，就不會去。

**判斷**：物件系統「存在於世界」，但不存在於決策。刷新前後行為幾乎不變，仍是 recall/lane。

### 2.5 兵線推進與塔攻擊紀錄

**數據**

- 全樣本 `firstOuterTowerSec` missing **100%**
- 場均 towers = **0**
- siege action ≈ **0.1%**
- 全隊 CS even 場均 **28.3**（40 分鐘十人總和）

**程式依據**

- 兵線有生成與互打（`minion/lane-system.ts`）。
- 英雄補刀走 `tryLastHit`，但 AI 幾乎不選 farm。
- 推塔條件：`t > 480`、`hpRatio > 0.5`、且「有己方兵靠近塔」或人在塔外。
- 塔優先打兵再打人（合理），但英雄很少帶線進塔。
- `laneTarget` 只走到線上路徑前段點，**不是跟著兵線推進**。

**判斷**：兵線是背景動畫，不是營運工具。沒有控線、推進、換線、圍塔節奏。

### 2.6 技能使用率、命中、傷害占比

**數據（even）**

- 場均 ability casts：**31.8**
- 場均 auto attacks：**48.3**
- ability damage share（對能力量粗分）：**37%**
- 40 分鐘只有約 32 次施法 → 平均每英雄約 3 次／場

**程式依據**

- 技能主要在 `fightTarget` → `castKit` 一次丟 QWER。
- 多數英雄是 generic partial executor；少數有 special。
- 沒有命中判定模型（目前是範圍內直接结算），因此「命中率」指標目前無法真測，只能測「嘗試施放次數」。

**判斷**：技能不是戰鬥主軸；也還沒有職業級的技能差異與命中互動。

### 2.8 經濟成長與裝備購買

**數據（even）**

- 人均終局金約 **3301**
- 被動金理論值：`1.2/s * 2400 + 500 start ≈ 3380`
- 結論：經濟幾乎 = 站樁被動金
- 全隊 CS ≈ 28；等級終局均值 **1.13**（大量英雄整場 1 級）
- 樣本 levelsAtEnd 常見：`[1,1,1,1,1,1,1,3,1,1]`

**程式依據**

- `passiveGoldPerSec = 1.2`（`shared-content.ts`）
- 經驗主要靠 CS（約 30+）與野怪 `exp`
- 因為 farm/jungle action 趨近於 0 → 經驗鏈斷裂 → 永久 1 級
- 買裝只在泉水距離 < 500 時嘗試；且清單極粗

**這是本報告最關鍵的煙霧彈解除點：**

不是「傷害公式稍微弱」，而是 **成長系統實質沒有轉起來**。1 級英雄打 40 分鐘，不可能出現職業賽曲線。

**判斷**：目前「比賽結束」不是玩出來的，是時間到了裁判吹哨。

## 3. 根因排序（依證據強度）

### P0 — 成長迴路失效（CS／野區／經驗）

- 現象：終局等級 ≈ 1、CS 極低、金幣≈被動金
- 影響：後面所有戰鬥、推進、收尾都不可能正常
- 不是調擊殺率能解

### P0 — AI 被 recall 狀態吞掉

- 現象：recall 占 60–90% 決策時間
- 影響：沒人待在線上經營，farm/siege/jungle 無從發生
- 可能交互：1 級互毆 → 殘血 → 長途回城 → 再互毆

### P0 — 完全沒有物件決策

- 現象：龍／巴龍刷新前後行為不變，且 0 次擊殺物件
- 影響：沒有職業賽中段節奏與故事節拍

### P1 — 沒有兵線營運與自然推塔

- 現象：0 塔、siege≈0
- 影響：無法自然結束，只能 overtime

### P1 — 交戰模型是「遇見就打」

- 現象：首殺過早、團戰極少、傷害極低
- 影響：結果不像職業賽，也不像正常排位節奏

### P2 — 英雄差異不足

- 多數 generic skill；非當前阻塞主因，但會限制長期上限
- 符合「架構可進場 ≠ 機制完整」的區分

## 4. 對你提出方向的回應（診斷立場）

1. **同意**：保留 V2，不把 V1 事件塞回結果。
2. **同意**：先診斷再改；本次未調擊殺率／未做結果整形。
3. **同意**：KPI 要分均勢／優勢／碾壓；目前 V2 這三種幾乎同構。
4. **補強發現**：在進 Phase 2「戰術 AI」之前，必須先修 **P0 成長迴路與 recall 失控**，否則更高級決策沒有資源與等級可決策。
5. **關於英雄完整度**：目前狀態是  
   - 架構支援：大致做到（都能進場）  
   - 機制完整：未做到  
   - 平衡驗證：遠未開始  
   不應把 generic template 說成「已支援完整英雄」。

## 5. 建議的下一步（仍不直接大改，先定修復順序）

若同意本報告，建議實作順序：

1. **Fix growth loop**  
   讓英雄穩定獲得 CS／野怪經驗與等級；人均 20 分應到合理等級帶。
2. **Fix recall / lane presence**  
   降低無效回城時間，確保線上有人經營。
3. **Add objective intent（最小戰術層）**  
   龍／巴龍刷新前開始集結或換線，而不是抽擊殺。
4. **Add wave-based sieging**  
   跟著兵線推，讓外塔能自然倒下。
5. **然後才做更深戰術 AI／技能差異**

每一步都應用本報告同款 KPI 回歸：  
時長分布、擊殺、首塔、龍、強制結束率、等級／CS、三種對局分化。
