# 對線期規則（引擎應遵守）

整理自真服 wave management，對應本專案意圖。

## 1. 補刀（Last Hit）

1. CS 只在英雄攻擊距離附近取得；普攻／技能打死才是正常來源。
2. 小兵互砍或塔殺時，允許極短距離的 Soft Last Hit（模擬離散 tick），但不能跨河／跨塔「隔空吃兵」。
3. 沒有人在波附近 → 兵自然死掉，不記給線權英雄。
4. Support 不搶 ADC 刀；Shared Riches 例外另算。

## 2. 預設對線（Default Farm）

1. 站在兵線附近（貼近普攻距離），不要 zoom out 站到半條線外。
2. Spacing 是進出威脅圈，不是永遠站在自己最遠射程外。
3. 補刀時允許短暫走進敵方普攻圈；補完再退。
4. 移動用短步右鍵：朝目標點一小步（約 200 單位），高頻更新；禁止正弦亂抖，也禁止一次走完整條線。
5. 攻走節奏：能補就普攻，攻完／等 CD 再點回安全位；等刀時待在普攻圈內，不要來回空晃。
6. 站在己方兵線旁不算「被小兵壓制」；只有超車己方兵線又沒有兵擋住才撤退。
7. 被壓或殘血時優先縮到經驗圈／可補刀邊緣（約兵線錨點 1000 內），不要躲到連 XP 都吃不到；致命威脅或塔下才深退。己區且敵人不在普攻威脅圈時，仍可謹慎補刀。
8. 攻擊敵方英雄會拉附近敵方小兵轉火；換血要付小兵代價。遠程可在手長優勢外 poke；近戰高爆發仍可短窗口換血。

## 3. 壓刀（Freeze）

1. **只補刀**，不放技能清線、不亂普攻滿血兵。
2. Clash 目標：己方外塔外側（塔攻擊圈外一點），敵兵略多於己兵。
3. 觸發傾向：落後、殘血、要安全發育、己方區有可凍的線。
4. 破凍：對手大力推線、己方要搶線權／召回前推、目標窗口強制 shove。

## 4. 推線（Shove）

1. **Hard Shove**：優先打遠程兵與殘血，技能可清線，目標是 Crash。
2. **召回／目標前**：若線還在 own／river，先 shove 到 Crash 再離開。
3. Crash 後暫時不要繼續站在敵塔下硬清下一波（除非圍塔／強勢）。

## 5. 線權（Lane Priority）

1. Crash 成立或敵方區兵線已被清空 → 視為有線權窗口。
2. 窗口用途：召回、遊走、佈視、協助打野／小龍／前線。
3. 沒線權時，優先處理兵線，不空手離線。

## 6. Bounce

1. Crash 後預期下一波往己方退；可接 Freeze 或安全補刀。
2. 被 Crash 進塔時：先清線保塔，再判斷是否被反壓。
